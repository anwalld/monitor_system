# Spec Delta

## Purpose

让 Worker 的每块网卡都能被单独使用和单独测量：从某块网卡地址发出、或绑定到某块网卡发出的流量必须从这块网卡离开，多网卡链路质量探测才有意义。

## ADDED Requirements

### Requirement: 每块网卡一张独立路由表
策略路由脚本 SHALL 为每块参与的网卡分配一张独立路由表，表内包含经该网卡网关的默认路由，并添加两条规则：源地址为该网卡 IPv4 地址时查该表；出接口为该网卡时查该表。网卡、网关、表号 MUST 可通过参数或配置文件指定，未指定网关时从该网卡现有路由推断。

#### Scenario: 按源地址出网
- **WHEN** 脚本对 eth0、eth1 执行完成后，运行 `ping -I <eth1 的 IP> 8.8.8.8`
- **THEN** 报文从 eth1 发出并收到应答（可用 `tcpdump -i eth1 icmp` 观察）

#### Scenario: 按出接口出网
- **WHEN** 脚本执行完成后，运行 `ping -I eth1 8.8.8.8`（绑定到网卡）
- **THEN** 报文从 eth1 发出并收到应答

#### Scenario: 推断不到网关
- **WHEN** 某块网卡既没有在参数中给出网关，也没有可推断的现有路由
- **THEN** 脚本对该网卡报错并以非 0 退出，不改动任何网卡的路由

### Requirement: 策略路由幂等且可撤销
脚本 MUST 支持重复执行而不产生重复的规则或路由，并 SHALL 提供撤销模式，删除自己添加的全部规则和路由表内容。

#### Scenario: 重复执行
- **WHEN** 连续执行两次脚本
- **THEN** `ip rule` 中每块网卡仍只有一条 from 规则和一条 oif 规则

#### Scenario: 撤销
- **WHEN** 以撤销模式执行脚本
- **THEN** 脚本添加的规则和路由表内容全部删除，主路由表不受影响

### Requirement: 不影响主机原有默认出网
添加策略路由后，未指定源地址、未绑定网卡的流量 MUST 仍按主路由表出网。

#### Scenario: 普通出网
- **WHEN** 脚本执行完成后运行不带 `-I` 的 `ping 8.8.8.8`
- **THEN** 报文从主路由表的默认网卡发出并收到应答
